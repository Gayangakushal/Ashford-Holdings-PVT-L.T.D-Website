# Ashford Holdings PVT L.T.D — website

Marketing site for Ashford Holdings PVT L.T.D, an air and environmental engineering company in Sri Lanka. Built with TanStack Start, React 19, TypeScript and Tailwind CSS v4. The project is connected to Lovable.

For the origin of every fact and image, see [SOURCE-NOTES.md](SOURCE-NOTES.md).

## Development

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # Cloudflare Worker output in .output/
npx tsc --noEmit
npm run lint
```

## Routes

| Path | Purpose |
| --- | --- |
| `/` | Home |
| `/solutions`, `/solutions/:slug` | The six disciplines, plus the original 14 engineering-system pages (old URLs still work) |
| `/projects`, `/projects/:slug` | Projects confirmed by named client feedback |
| `/industries`, `/industries/:slug` | 12 sectors; old industry slugs map to their new equivalents |
| `/about`, `/leadership`, `/contact` | Company, people, enquiry |
| `/products`, `/products/:slug`, `/brands` | Equipment range and referenced brands |
| `/privacy`, `/terms` | Legal |

`public/sitemap.xml` is generated by `node scripts/generate-sitemap.mjs`. Re-run it after adding projects, industries or solutions.

## Structure

- `src/data/` holds all content. Each file says which source it comes from.
- `src/components/site/` holds the component system: `Header` (with the full-screen mobile menu), `home/Hero` and `home/AirflowCanvas`, `MetricStrip`, `AirflowIntelligence`, `SolutionSystem`, `SolutionFeature`, `IndustryGrid`, `ProjectCard`, `RackingDrawing`, `NetworkMap`, `WhyAshford`, `LeadershipSection`, `TestimonialSlider`, `LogoMarquee`, `CTA`, `ContactSection`, `PageHero` and `Footer`.
- `src/styles.css` holds design tokens and the type scale. `src/components/site/site.css` holds component styles, inside `@layer components` so Tailwind utilities can override them.
- `src/data/world-dots.ts` is the generated dotted world map (from world-atlas land-110m, equirectangular). Don't edit it by hand.

## Motion

There are no animation libraries. Motion uses CSS, IntersectionObserver, one canvas (the hero airflow) and SVG.

- Scroll reveals hide content only once JavaScript has added `html.js`, so the page stays readable without JS.
- `prefers-reduced-motion` turns off:
  - the canvas animation (a static frame of streamlines is drawn instead)
  - the marquee (the logos wrap in a static grid)
  - auto-advance of the air-path stages
  - all transitions
- Touch devices get fewer particles and no cursor effects.

## Contact form

There is no form backend. Submitting the form validates it, then opens the visitor's email client with the enquiry prepared for info@sairt.com. To store enquiries server-side, connect a backend.

## QA scripts

These need `playwright-core` and a local Chrome:

```sh
node scripts/site-smoke.mjs <playwright-core/index.mjs> http://localhost:5173 artifacts/qa
node scripts/interaction-smoke.mjs <playwright-core/index.mjs> http://localhost:5173 artifacts/qa
```

`site-smoke` loads every route at 1920, 1440, 1280, 1024, 768, 430, 390, 375 and 360px. It checks for console errors, failed requests, horizontal overflow, broken images and the heading structure.

`interaction-smoke` tests:
- the mobile menu (focus trap, Escape, closing on navigation)
- the header compacting on scroll
- the testimonial slider, including keyboard control
- the solutions accordion and the air-path stages
- the marquee (loop integrity and pause on hover)
- reduced motion and no-JS rendering
- the skip link and form validation
