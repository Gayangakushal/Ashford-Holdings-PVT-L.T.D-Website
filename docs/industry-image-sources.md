# Industry card image sources

Checked 2 October 2026. All 12 cards use different real photographs. No images were generated.

The existing project assets were inspected first. Manufacturing retains the supplied extraction installation photograph; Energy & Utilities retains the supplied heat-exchanger plant photograph. These are representative engineering images, not verified photographs of named client projects. The project's SOURCE-NOTES.md identifies the HVAC photographs as user-supplied assets.

The remaining photographs are saved into `public/assets/industries/` as local copies. The website currently references their verified `images.pexels.com` URLs because the user's preview did not serve the newly added local files. All ten CDN URLs were checked for HTTP 200 and an image content type. Displaying these ten photographs requires access to the Pexels image CDN. They depict representative industry environments and do not establish client relationships, project delivery, location, or endorsement.
